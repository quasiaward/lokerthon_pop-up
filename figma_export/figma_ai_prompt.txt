아래 요구사항을 바탕으로 Figma에서 편집 가능한 데스크톱 웹사이트 시안을 만들어줘.

첨부 이미지 참고
- `haenggung_desktop_first_fold.png`: 첫 화면/헤더/히어로 참고용
- `haenggung_desktop_long_page.png`: 전체 페이지 흐름 참고용
- 이미지는 분위기와 레이아웃 참고용으로 사용하고, 최종 결과는 편집 가능한 Figma 레이어와 Auto Layout으로 재구성해줘.

프로젝트
- 브랜드명: 행궁다과
- 웹사이트 성격: 화성행궁 근처 전통 디저트 카페/체험/케이터링 홈페이지
- 목표: 고급스럽고 정갈한 전통 다과 브랜드 이미지를 전달하면서, 메뉴 확인, 체험 예약, 케이터링 문의, AI 다과 추천으로 자연스럽게 이동하는 홈페이지
- 우선순위: 데스크톱 웹 중심. 모바일 반응형은 후순위.

전체 디자인 방향
- 분위기: 전통적이지만 촌스럽지 않고, 조용하고 세련된 프리미엄 한옥 찻집 느낌
- 키워드: 정갈함, 명인, 전통 다과, 화성행궁, 한지 질감, 따뜻한 차, 절제된 고급감
- 레이아웃: 넓은 여백, 균형 잡힌 그리드, 정보가 많은 섹션도 복잡해 보이지 않게 구성
- 카드 radius는 8px 이하로 유지
- 과한 장식, 둥근 말풍선 남발, 보라색/파란색 그라데이션, 랜딩페이지식 과장된 마케팅 느낌은 피하기
- 모든 요소는 Figma에서 편집 가능한 텍스트/도형/컴포넌트로 구성

프레임
- Desktop frame: 1440 x 1024 이상
- 콘텐츠 최대 폭: 1180px
- 좌우 padding: 24px
- 주요 섹션 vertical padding: 88-96px
- 섹션 순서: Header > Hero > 소개 > 메뉴 > 체험 > 케이터링 > AI 다과 추천 > Footer

컬러 스타일
- Cream: #F7EFE4, 전체 배경
- Paper: #FFFCF7, 헤더/카드/폼 표면
- Hanji: #F1E7D8, 부드러운 필드/보조 패널
- Wheat: #D8C5AA, 보더/디바이더
- Porcelain: #E9F0EC, 차분한 보조 배경
- Deep: #211817, 메인 텍스트/다크 버튼
- Brown: #604537, 보조 텍스트
- Cinnabar: #87352D, 브랜드 포인트/섹션 eyebrow
- Gold: #C19A5B, 고급 포인트/포커스 라인
- Jade: #2F6F5E, 차/산뜻함 포인트
- Plum: #6A3A4A, 계절감 포인트
- Muted: #6D6258, 본문 보조 텍스트

타이포그래피
- 본문: Noto Sans KR
- 제목/브랜드: Noto Serif KR
- 브랜드 텍스트: 20px, 800, Deep
- 네비게이션: 16px, 800, Deep
- Section eyebrow: 11px, 600, letter spacing 4px, Cinnabar 또는 Gold
- Section title: 40px, 700, line-height 1.22, Noto Serif KR
- Section description: 16px, 300, line-height 1.82, Muted
- 카드 제목: 24-32px, 800, Noto Serif KR
- 본문: 14-16px, line-height 1.45-1.65

공통 컴포넌트
- Soft Card: Paper fill, Wheat 58% border, 8px radius, 26px padding, soft shadow
- Primary Button: Deep fill, Paper text, 8px radius, 24px x 16px padding
- Outlined Button: transparent/Paper fill, Deep 45% stroke, Deep text, 8px radius
- Form Field: Hanji 50% fill, Wheat border, Gold focus border, 8px radius, 14px padding
- Tag Pill: Gold 10% fill, Gold 30% stroke, Brown text, 999px radius, 10px x 5px padding

Header
- 높이: 72px
- 배경: Paper 95%
- 하단 보더: Wheat
- 왼쪽 브랜드: 원형 마크 안에 “宮”, 옆에 “행궁다과”, 작은 설명 “화성행궁 전통 다과”
- 오른쪽 메뉴: 소개, 메뉴, 체험, 케이터링, 다과 추천
- 정갈하고 가벼운 top navigation으로 구성

Hero
- 첫 화면에서 브랜드 정체성이 바로 보이게 구성
- H1: “화성행궁 곁, 명인이 빚은 다과.”
- 설명: “화성행궁 옆 2층 전통 디저트 공간입니다. 다과, 화전, 전통차, 빙수와 체험·케이터링 문의를 한곳에서 확인하세요.”
- CTA 버튼: “체험 문의하기”, “메뉴 보기”
- 우측 또는 배경에는 전통 다과/차/빙수 분위기의 이미지 영역을 크게 배치하되, 카드 안에 갇힌 느낌보다 실제 매장/메뉴가 드러나는 편집형 구성을 선호
- Gold 라인, 한지 질감 느낌의 얇은 디바이더, 작은 메뉴 키워드 칩 사용

소개 섹션
- Eyebrow: ABOUT
- Title: “행궁동 전통 디저트”
- Description: “화성행궁 인근 2층 찻집. 다과, 전통차, 계절 빙수를 즐길 수 있습니다.”
- 구성: 브랜드 스토리 + 핵심 포인트 3-4개
- 포인트 예시: 화성행궁 옆 2층, 떡공예 명인 운영, 다과·전통차, 빙수·포장 다과

메뉴 섹션
- Eyebrow: MENU
- Title: “행궁다과 메뉴”
- Description: “대표 다과, 화전, 전통차, 빙수의 주요 메뉴와 가격을 정리했습니다.”
- 메뉴 카드:
  1. 다과상 / Traditional Sweets Tray / 7,000원 / 대표 다과
  2. 진달래화전 / Azalea Flower Pancake / 7,000원 / 전통 디저트
  3. 대추차 / Jujube Tea / 9,000원 / 전통차
  4. 쌍화차 / Ssanghwa Herbal Tea / 9,000원 / 전통차
  5. 생강차 / Ginger Tea / 7,000원 / 전통차
  6. 망고빙수 / Mango Bingsu / 15,000원 / 빙수
  7. 녹차빙수 / Green Tea Bingsu / 15,000원 / 빙수
  8. 행궁약과 / Haenggung Yakgwa / 2,500원 / 개별 다과
- 카드에는 메뉴명, 영문명, 설명, 가격, 카테고리 태그, 작은 한자/심볼을 넣기
- 카드들이 너무 무겁지 않게 3-4열 그리드로 정돈

체험 섹션
- Eyebrow: EXPERIENCE
- Title: “떡 만들기 체험 예약”
- Description: “체험 전 확인이 필요한 일정은 여기서 남겨 주세요.”
- 폼 항목:
  - 유형: 개인 / 소규모 / 단체
  - 날짜
  - 시간
  - 인원: 개인이면 숨김, 소규모는 2-10명, 단체는 10명 이상
  - 이름
  - 연락처
  - 기타 요청 사항
- 폼은 넓고 안정적인 2열 배치, 요청 사항은 아래 넓게
- CTA: “체험 문의 보내기”

케이터링 섹션
- Eyebrow: CATERING
- Title: “케이터링 문의”
- Description: “인원, 예산, 구성 요청을 현실적인 흐름으로 남겨 주세요.”
- 폼 항목:
  - 인원 수: 숫자 입력 또는 stepper
  - 예산: 3만원, 5만원, 10만원, 15만원 선택형
  - 희망 구성: 다과, 약과, 화전, 전통차 등 체크
  - 일정
  - 장소 또는 픽업 여부
  - 기타 요청 사항
- 요청사항 입력칸의 placeholder는 작고 세련되게, 가운데 크게 노출하지 말 것
- CTA: “케이터링 문의 보내기”

AI 다과 추천 섹션
- Eyebrow: AI RECOMMEND
- Title: “AI 다과 추천”
- Description: “개별 다과 유형과 취향 신호를 비교해 한 가지 메뉴를 제안합니다.”
- 이 섹션은 어두운 배경을 사용:
  - Gradient: Deep #211817 > #30211D > #162B27
  - 텍스트는 Paper/Hanji, 포인트는 Gold
- 입력 패널:
  - 성향
  - 상황
  - 단맛
  - 식감
  - 차 취향
  - 선택 스타일
  - 오늘의 취향 메모
- 결과 패널:
  - 추천 프로필
  - 다과 유형 badge
  - 추천 메뉴명
  - 유형 설명
  - 매칭도 badge
  - 추천 이유 3개
  - 함께 어울리는 메뉴/차
  - 차선 추천
- 중요한 조건:
  - 결과는 다과상 같은 구성 상품이 아니라 개별 다과 하나를 추천하는 느낌
  - 예시 추천: 행궁약과 / 유밀과·모약과
  - 태그 예시: 약과 추천, 선물성, 수원 기념성, 포장 문의

Footer
- 브랜드명 “행궁다과”
- 짧은 설명: “화성행궁 곁에서 다과, 전통차, 빙수와 포장 다과를 만나는 공간입니다.”
- 문의/위치/운영 정보가 들어갈 수 있는 정돈된 3열 구조

- Color Styles와 Text Styles 적용
