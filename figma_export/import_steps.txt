Figma로 가져오는 가장 안정적인 순서

1. 로컬 페이지 열기
   http://127.0.0.1:5175/

2. 전체 페이지 캡처
   Chrome > Cmd + Option + I > Cmd + Shift + P > Capture full size screenshot

3. Figma에 PNG 드래그
   캡처 이미지를 Figma 캔버스에 넣고 Lock 처리합니다.

4. figma_handoff.md 기준으로 Styles 생성
   Color Styles, Text Styles, Button, Card, Field, Tag 컴포넌트를 먼저 만듭니다.

5. 섹션별 재구성
   Header, Hero, 소개, 메뉴, 체험, 케이터링, AI 다과 추천, Footer 순서로 Auto Layout을 사용해 다시 그립니다.

주의
- Flutter Web은 일반 HTML 페이지와 달라서 html.to.design 같은 플러그인으로 완전한 편집형 변환이 잘 안 될 수 있습니다.
- 발표/제출 목적이면 PNG 캡처만으로 충분합니다.
- 피그마에서 세부 수정이 필요하면 캡처를 배경으로 깔고 위에 컴포넌트를 재구성하는 방식이 제일 깔끔합니다.
