# 행궁다과 demo ver0

수원 행궁동 전통 다과 브랜드 **행궁다과**의 로커톤 발표용 Flutter 웹 데모입니다. `행궁다과_홈페이지_기획서.pdf`의 방향에 맞춰 공식 홈페이지 구조, 체험 예약, 케이터링 주문, 다국어 메뉴판, AI 안내 챗봇, AI 다과 처방 기능을 한 화면형 웹사이트로 구현했습니다.

## 기술 스택

- Flutter
- Dart
- Flutter Web
- 별도 백엔드 없음

## 실행 방법

```bash
flutter pub get
flutter run -d chrome
```

특정 포트로 실행하려면:

```bash
flutter run -d chrome --web-port 5174
```

## 주요 기능

- 행궁다과 브랜드 랜딩페이지
- 브랜드 스토리텔링: 1795년 화성행궁 연회, 원행을묘정리의궤, 다과 처방전 콘셉트
- 한/영/일 다국어 메뉴판
- 체험 예약 접수 폼과 사장님 SMS/구글 시트 저장 흐름 미리보기
- 케이터링 커스텀 주문 폼과 견적 회신용 요약
- 방문 목적, 맛, 예산, 상황 입력 기반 AI 다과 처방 엔진
- 추천 신뢰도, 입력 신호, 추천 이유, 차 페어링, 선물 메시지 표시
- 전 페이지 공통 플로팅 AI 안내 챗봇
- 추천 결과 복사
- 추천 결과 다시 받기
- 데스크톱/모바일 반응형 레이아웃

## 코드 구조

```text
lib/
  data/          상품 및 추천 엔진 데이터
  models/        추천 입력/결과와 카드 모델
  services/      로컬 추천 엔진
  theme/         컬러와 앱 테마
  widgets/       홈페이지 섹션, 예약/주문 폼, 챗봇, 공통 위젯
  main.dart      앱 진입점
```

추천 엔진은 `lib/services/recommendation_service.dart`에 분리되어 있어, 공개 데모에서는 프론트엔드 단독으로 동작하고 이후 Claude API, SMS API, Google Sheets API로 확장하기 쉽도록 구성했습니다.
